# Hoja de vida web — Erwin Obregón Meneses

Sitio estático desarrollado con HTML, CSS y JavaScript. Está preparado para publicarse gratuitamente en GitHub Pages.

## Contenido
- `index.html`: estructura y contenido de la hoja de vida.
- `styles.css`: estilos y diseño adaptable a móviles.
- `script.js`: menú móvil, control de tema y año automático.
- `assets/CV_Erwin_Obregon_Meneses.pdf`: copia del CV original para consulta/descarga.

## Publicación en GitHub Pages
1. Crea o inicia sesión en https://github.com/.
2. Crea un repositorio público llamado exactamente `TU-USUARIO.github.io` (reemplaza `TU-USUARIO` por tu usuario de GitHub).
3. Descomprime este paquete y carga en la raíz del repositorio los archivos `index.html`, `styles.css`, `script.js` y la carpeta `assets`.
4. En GitHub abre **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
7. Espera a que termine el despliegue y visita `https://TU-USUARIO.github.io/`.

## Actualizaciones
Edita los archivos localmente y vuelve a subir los cambios al repositorio. GitHub Pages desplegará la nueva versión.

## Antes de publicar
- Revisa que deseas mostrar públicamente tu correo y número telefónico.
- Verifica que el PDF adjunto sea la versión de tu CV que deseas compartir.
- Comprueba la ortografía, fechas y descripción de cada cargo.
- La información académica y laboral se presenta según el CV suministrado; actualiza cualquier dato que haya cambiado.

## Alcance técnico
Este proyecto es un sitio estático. No incluye backend, base de datos ni formularios que almacenen información.
